## Implementation boundaries
- Existing public `index.html`, AI assets, GitHub Pages workflow and encrypted browser workspaces remain unchanged.

- Six canonical families: MUSITU Axiom, Education, Frontier Market Intelligence, Foundry, Markets, WorldFabric.
- Product claims must show a maturity state, source and known limitations.
- Company legal identity, corporate contact, and official domain require owner verification.

- Publish only with a dedicated, approved build and release workflow; no auto-deploy.
